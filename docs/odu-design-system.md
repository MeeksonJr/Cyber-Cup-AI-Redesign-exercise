# ODU Design System - CyberCup.AI

## Color Palette

### Primary Colors

| Color Name | HEX | RGB | Usage |
|------------|-----|-----|-------|
| **Monarch Blue** | #043657 | 4, 54, 87 | Primary brand color, headers, CTAs |
| **Hudson Blue** | #98C5EA | 152, 197, 234 | Accents, highlights, secondary elements |
| **Silver Reign** | #828A8F | 130, 138, 143 | Muted text, borders, subtle elements |

### Secondary Colors

| Color Name | HEX | Usage |
|------------|-----|-------|
| **Ultramarine Blue** | #1a4b8c | Digital only, hover states |
| **Electric Teal** | #00b4d8 | Digital only, interactive elements |

## Typography

### Primary Fonts

- **Monte Stella** (Display): Headlines, subheads, statistics
- **Sora** (All-purpose): Body copy, subheads, quotes, captions
- **Open Sans** (Web only): Body copy on website

### Font Usage Guidelines

1. Use Montserrat for display/headline text (as Monte Stella alternative)
2. Use Sora for body copy and general text
3. Maintain clear hierarchy with proper font weights
4. Never use decorative fonts for body text

## Spacing & Layout

- Use generous white space with Monarch Blue and Silver Reign
- Mobile-first responsive design
- Consistent padding scale: 4px, 8px, 16px, 24px, 32px, 48px, 64px

## Components

### Buttons
- Primary: Monarch Blue background, white text
- Secondary: Hudson Blue background, Monarch Blue text
- Hover states use Ultramarine Blue

### Cards
- White background in light mode
- Subtle shadow for depth
- Rounded corners (0.625rem)

### Navigation
- Monarch Blue for primary nav items
- Hudson Blue for active/hover states

## Brand Voice

- Bold and confident
- Technical yet approachable
- Educational and empowering

## Do's and Don'ts

### Do
- Lead with Monarch Blue for official communications
- Use ample white space
- Maintain consistent typography hierarchy

### Don't
- Use black prominently or in large floods
- Mix too many colors
- Use gradients without purpose
